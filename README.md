# Gate check-in

Static QR check-in page for event gates. Open with `?e=<Apps Script deployment id>`; the page talks to that web app's JSON API (POST, text/plain). PIN login, camera scan, typed code or name/phone search, party count and Admit.

Scanner library: html5-qrcode 2.3.8 (Apache-2.0, see `html5-qrcode.LICENSE`).
